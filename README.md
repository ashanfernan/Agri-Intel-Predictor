# 🌾 Agri-Intel Predictor

An AI-powered agricultural yield prediction application designed for data-driven precision farming. Built using **Python**, **Scikit-Learn**, and **Streamlit**.

---

## 📌 Features
- 📊 **Yield Prediction:** Predicts crop output based on environmental and input factors.
- ⚡ **Interactive Web Interface:** Easy-to-use Streamlit dashboard for real-time inference.
- 🎯 **Zero-Input Analytics:** Optimized machine learning pipeline for fast data processing.

---

## 🛠️ Tech Stack & Dependencies
- **Language:** Python
- **Machine Learning:** Scikit-Learn, Pandas, NumPy
- **Web Framework:** Streamlit
- **Model Serialization:** Pickle (`agri_intel_model.pkl`)
